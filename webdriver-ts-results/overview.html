Benchmark documentation ↗
01 CPU performance
Time to create, update, select, and remove table rows, including the browser’s rendering work. Lower durations mean faster operations.
02 Memory usage
Memory used after page load and repeated table operations. Lower values mean a smaller memory footprint for the measured task.
03 Startup & size
Loading and startup measurements vary by release. Check each report’s descriptions and units when comparing time or transfer size.

Compare within the same release. Browser versions, CPU throttling, and measurement methods change over time. Since Chrome 118, the overall result uses a weighted geometric mean. See how duration is measured.

Keyed and non-keyed implementations handle DOM identity differently. Compare the mode that fits your application; these table operations are one part of choosing a framework.
